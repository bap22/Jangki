# Jangki - Korean Chess

A modern, real-time multiplayer Jangki (Korean Chess) game built with Next.js and hosted on Vercel.

## Features

- 🎮 Complete Jangki game logic with all traditional rules
- 👥 Real-time 2-player multiplayer
- 🏠 Game room system
- 📱 Responsive design
- ⚡ Serverless API on Vercel

## How to Play

1. Create or join a game room
2. Red moves first
3. Capture the opponent's General (Janggun) to win

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Socket.IO for real-time communication
- Vercel for hosting

## Development

```bash
npm install
npm run dev
```

## Deployment

Deploy automatically to Vercel on push to main branch.
